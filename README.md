# 落雪音乐下载器

一个面向 Windows 的 Electron 桌面音乐下载工具。它提供落雪风格的搜索与下载队列，支持本地导入和更新洛雪音乐 JS 音源，并可把已经下载到电脑的音频提交给飞牛 NAS，由 FNOS-API 负责拉取到 NAS 目标目录。(目前这个功能的实现还是有点问题，可以通过开启smb局域网共享添加网络位置，把下载位置改到网络位置实现下载到NAS文件夹的功能)



做这个功能的初衷是想让下载好的音乐文件进入NAS指定位置，通过[music tag web](https://github.com/xhongc/music-tag-web)项目自动刮削之后，直接在飞牛音乐里面可以听新下载的歌曲，当然也可以接入其他的手机的音乐软件，方便下载无损音乐和在手机上听歌，也欢迎大佬们帮写一下看下怎么样把飞牛的skill改成能上传到自己本地飞牛NAS上面指定文件夹的功能，当然当前通过网络位置的这个方法也能实现这个功能就是了



## 功能

- 搜索酷我音乐、酷狗音乐、企鹅音乐和网易音乐，也支持聚合搜索。
- 搜索结果自动带入平台曲目 ID、歌手、专辑、时长和可用音质。
- 支持导入 `.js` 音乐源；更新已有音乐源时会保留旧版本备份。
- 内置多个备用音乐源；当当前音源的直链服务异常时，会自动轮换备用解析源。
- 音乐源在隔离 worker 中执行，下载前会提示确认。
- 下载队列支持“仅下载”和“提交已下载到 NAS”两个独立操作。
- 本机下载目录可以在“连接设置”中选择，默认是 Windows“下载/落雪音乐下载器”。
- 通过 FNOS-API `9932` 端口提交 NAS 下载任务，提交前调用文件预检接口，避免覆盖已有文件。
- FNOS-API 地址、Token 和 NAS 目标目录使用 Windows 凭据加密保存。

## 下载流程

1. 在“音乐源”页面导入一个洛雪音乐 JS 音源。
2. 在“搜索音乐”页面选择平台并搜索歌曲。
3. 将歌曲加入“下载队列”，选择音质。
4. 点击“仅下载”，歌曲会保存到设置页指定的本机目录。
5. 确认歌曲状态为“已完成”后，点击“提交已下载到 NAS”。提交操作只处理本机已有文件，不会重复下载。

NAS 提交时，桌面端会在电脑上创建带一次性令牌的局域网文件流，然后调用 FNOS-API 的 `/api/file/check-upload` 和 `/api/download/add-uri`。NAS 需要能够访问电脑的局域网地址，提交后请在飞牛下载任务中查看远端完成状态。

## FNOS-API 配置

在“连接设置”中填写：

- **API 地址**：例如 `http://ip:9932`
- **API Token**：FNOS-API 安装配置中生成的自定义 Token
- **目标目录**：例如 `/vol1/music/下载`
- **本机下载位置**：选择电脑上的音乐保存目录

FNOS-API 服务的 REST 端口是 `9932`。FNOS-API 安装配置中的 NAS 地址和 WebSocket 端口属于服务内部连接设置，WebSocket 默认端口通常是 `5666`。修改 FNOS-API 配置后需要重启服务。

## 安装和使用

### 使用便携版

从 Releases 下载 `落雪音乐下载器-*-便携版.exe`，双击运行即可。便携版当前未配置代码签名，Windows SmartScreen 可能显示提示。

### 从源码运行

需要 Node.js 18 或更高版本：

```powershell
npm install
npm run dev
```

### 打包 Windows 便携版

```powershell
npm run pack
```

产物会输出到 `release/`。生成安装包和便携版可以使用：

```powershell
npm run dist
```

## 音乐源说明

仓库中的 `lx-music-source-v7.js` 作为首次启动时的默认音源。音乐源由用户在本机导入和更新，软件不会修改原始 JS 文件。音乐源代码可能访问第三方音乐平台，请在使用前确认相关平台的服务条款和当地法律要求。

## 隐私和安全

- 搜索词会发送到所选音乐平台的搜索接口。
- 下载时会执行用户主动导入的本地音乐源代码，并访问音乐平台返回的音频直链。
- FNOS-API Token 只保存在本机的 Windows 加密存储中，不写入仓库或日志。
- 本地文件只会通过临时局域网地址提供给已配置的 NAS 下载任务。
- 请不要把真实 Token、NAS 密码、个人配置文件或下载目录中的音乐文件提交到 Git。
